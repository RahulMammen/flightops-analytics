# Reports

Generated by:

```powershell
python -m flightops.cli all --seed 20260101
```

That is the default seed and generator config: 84 aircraft, 120 days from 2026-01-01, a 1.5% cancellation
probability per out-and-back pair, 1.5% duplicates, 0.8% each of missing fields, invalid timestamps and impossible
durations, and 0.2% rows with overlapping defects. Run on 2026-10-18 with Python 3.12.10 and DuckDB 1.5.6.

| File | Contents |
|---|---|
| `pipeline_report.json` | Ingestion result and log, reconciliation, reason codes and definitions, summary metrics, turnaround stats, Parquet outputs, rule check |
| `defect_detection.csv` | Injected defects versus pipeline outcome, per defect type |
| `route_performance.csv` | Per-route scheduled, operated, cancellation rate, on-time rate, delay p50 and p90, mean block time |

The committed `pipeline_report.json` comes from the second (idempotency) run, so its `ingestion` field shows
`"skipped": true`. The `ingestion_log` field shows the original batch: 50,924 rows inserted.

The data is synthetic. Generated data, the DuckDB file and the Parquet files are not committed. They are
recreated deterministically by the command above.
